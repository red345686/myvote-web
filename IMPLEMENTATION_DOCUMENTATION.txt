1. PROJECT OVERVIEW
===================

MyVote Web is a blockchain-based voting administration platform built with Next.js,
TypeScript, and React. The application provides a secure and transparent interface
for managing elections, voter registration, and verification processes.

Key Features:
- Voter registration and verification
- Election scheduling and management
- Candidate management
- QR code-based voting system
- Real-time statistics and analytics
- Admin dashboard with comprehensive controls

Technology Stack:
- Frontend: Next.js 14, React 18, TypeScript
- Styling: Tailwind CSS, Framer Motion
- Blockchain: Ethers.js (with dummy mode for development)
- UI Components: Heroicons, React Hook Form
- QR Code: html5-qrcode library

4. USER INTERFACE IMPLEMENTATION
================================

4.1 Admin Dashboard (dashboard/page.tsx)
----------------------------------------
Purpose: Main admin control center with overview statistics

Components:
- Real-time statistics cards (Total/Verified/Pending voters)
- Gender distribution charts
- State-wise voter distribution
- Quick navigation links
- Refresh functionality

Statistics Display:
- Total registered voters
- Verified voters with percentage
- Pending verifications
- Verification rate with progress bar
- Daily registration/verification counts

Visual Features:
- Framer Motion animations
- Responsive card layout
- Interactive hover effects
- Loading states with spinners

4.2 User Verification (verify-users/page.tsx)
---------------------------------------------
Purpose: Admin interface for verifying pending user registrations

Features:
- Paginated user list with search functionality
- Real-time verification status updates
- Bulk user management
- Detailed user information display
- Success/error notifications

User Interface:
- Search bar with debounced input
- Table view with user details (name, gender, district, ID)
- Verification buttons with loading states
- Pagination controls
- Refresh functionality

Data Flow:
1. Load users from API with pagination
2. Display user information in table format
3. Handle verification requests with optimistic updates
4. Show success/error feedback
5. Update user status in real-time

4.3 Election Scheduling (schedule-elections/page.tsx)
----------------------------------------------------
Purpose: Create and manage elections

Features:
- Election creation form with validation
- Date/time pickers for election schedule
- Election status tracking (Upcoming/Active/Ended)
- List of scheduled elections
- Form reset after successful submission

Form Validation:
- Required field validation
- Date/time format validation
- React Hook Form integration
- Real-time error display

Election Status Logic:
- Upcoming: Start time > current time
- Active: Current time between start and end
- Ended: End time < current time

4.4 Candidate Management (manage-candidates/page.tsx)
----------------------------------------------------
Purpose: Add and manage candidates for elections

Features:
- Election selection dropdown
- Candidate addition form
- Candidate listing with details
- Election-specific candidate filtering
- Form validation and error handling

Workflow:
1. Select election from dropdown
2. Add candidates with name and information
3. View candidate list for selected election
4. Real-time updates after candidate addition

4.5 Statistics Dashboard (statistics/page.tsx)
----------------------------------------------
Purpose: Detailed analytics and reporting

Components:

- Gender distribution visualization
- Age distribution charts
- State-wise breakdown table
- Quick action links

Data Visualization:

- Responsive table layouts

4.6 QR Code Scanner (scanvoter/page.tsx)
----------------------------------------
Purpose: Scan voter QR codes for voting

Features:
